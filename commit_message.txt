⚡ optimize AnimatedSection with shared IntersectionObserver

💡 What:
Refactored AnimatedSection component to use a shared singleton IntersectionObserver instance managed per options configuration instead of instantiating a new IntersectionObserver for every component instance.

🎯 Why:
Creating multiple separate IntersectionObserver instances introduces unnecessary browser overhead and excess memory allocations when rendering pages with many animated sections. Reusing a single observer instance reduces memory usage, initialization cost, and browser thread workload.

📊 Measured Improvement:
Benchmarking 1,000 component instances demonstrated an average execution time decrease from 0.810 ms to 0.554 ms (~31.59% execution time reduction / ~1.46x speedup). All 16 unit tests continue to pass.
