⚡ optimize About component by caching age calculation

💡 What: Wrapped `calculateAge(personalData.birthDate)` inside a `useMemo` block with an empty dependency array in the `About` component, as the birthDate is a static constant imported from an external module.
🎯 Why: Prevents recalculation of age upon every re-render of the component, which eliminates redundant CPU usage and avoids unnecessary blocking of the main thread during render cycles.
📊 Measured Improvement: Verified the performance through benchmark tests where repeated re-renders (1000 and 500 loops) confirmed rendering happens slightly faster by skipping repeated data parsing and date instantiations for unchanging inputs.
