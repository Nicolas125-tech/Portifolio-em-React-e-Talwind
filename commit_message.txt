🧹 Refactor age calculation logic

🎯 What:
Refactored the embedded `calculateAge` function inside `About.jsx` out into its own dedicated utility module at `src/utils/calculateAge.js`.

💡 Why:
This improves maintainability and separation of concerns by pulling out a generic date-calculation utility from a React UI component. It also enables thorough and deterministic unit testing.

✅ Verification:
Added comprehensive tests covering edges cases (normal years, birthdays happening early, today, or later in the year, leap years, missing data). Mocked the system clock for reliable execution. Ran `npx vitest run` and everything passed successfully. Verified it doesn't break `About.jsx` rendering. Cleaned up untracked files used during reasoning steps.

✨ Result:
A cleaner UI component and an independently testable, robust date utility function.
